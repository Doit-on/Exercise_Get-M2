# Get INVOLVED! ม.2 - แบบฝึกหัดภาษาอังกฤษออนไลน์ (ทวพ. - TWP)
### เวอร์ชัน 2.0.0 (Account Authentication, Progressive E-Certificate & Google Sheets Sync)

เว็บแอปพลิเคชันแบบฝึกหัดภาษาอังกฤษออนไลน์ ระดับชั้นมัธยมศึกษาปีที่ 2 (ม.2) พัฒนาตามหลักสูตรหนังสือเรียน **Get INVOLVED!** โดย **บริษัท สำนักพิมพ์ ไทยวัฒนาพานิช จำกัด (TWP)** 
รองรับเนื้อหาตาม **แผนการสอน ม.2 ภาคเรียนที่ 2 (Unit 5 - Unit 8)**:
- **Unit 5: Must try!** (อาหาร เครื่องดื่ม และสถานที่ในเมือง)
- **Unit 6: Animals in danger** (สัตว์ป่าใกล้สูญพันธุ์และการอนุรักษ์ธรรมชาติ)
- **Unit 7: Heroes** (บุคคลต้นแบบและฮีโร่ในประวัติศาสตร์)
- **Unit 8: Summer fun** (กิจกรรมและการเดินทางช่วงฤดูร้อน)

## 🌟 ฟีเจอร์หลักครบถ้วนตามมาตรฐานระบบ ม.1

1. 🔐 **ระบบบัญชีนักเรียน (Student Account Authentication)**:
   - ป้องกันคะแนนสับสน/ไม่ต่อเนื่อง ด้วยระบบ Email & Password
   - จับคู่ชื่อ-นามสกุลและโรงเรียนอัตโนมัติเมื่อพิมพ์อีเมล
   - นำเข้ารายชื่อนักเรียนจาก Excel / CSV ได้ทันที

2. 🏆 **เกียรติบัตรอิเล็กทรอนิกส์ (Progressive E-Certificate)**:
   - ออกเกียรติบัตรสำหรับระดับชั้น ม.2 โดยเฉพาะ
   - มีระบบ Progressive Reveal เผยชื่อตามสัดส่วนแบบฝึกหัดที่ทำสำเร็จ (0%, 25%, 50%, 75%, 100%)
   - ดาวน์โหลด PNG คมชัดสูง, พิมพ์, หรือส่งเข้าอีเมลนักเรียนได้อัตโนมัติ

3. ☁️ **การเชื่อมต่อ Google Sheets Web App ในตัว**:
   - รองรับฐานข้อมูล 5 แผ่น: `Name_base`, `Students_DB`, `Scores_Log`, `Certificates`, `Login_Logs`
   - มีระบบเปลี่ยน Web App URL และปุ่มรีเซ็ตเป็นค่าเริ่มต้น

4. 🛡️ **ความปลอดภัยระบบคุณครู (Teacher PIN & Security)**:
   - ปิดซ่อนรหัสผ่าน PIN ครูจากหน้าจอ UI อย่างปลอดภัย
   - แถบแจ้งเตือน Toast และ Form Error ปิดตัวเองอัตโนมัติใน 5 วินาที พร้อมปุ่มปิด `✕`

5. 📱 **Single Page Application (Zero-Build & GitHub Pages Ready)**:
   - เปิดใช้งานได้ทันทีบนเบราว์เซอร์ ไม่ต้องติดตั้งโปรแกรมหรือรันคำสั่ง Build
   - มีไฟล์ `.nojekyll` และ `404.html` พร้อมนำขึ้น GitHub Pages ได้ทันที
